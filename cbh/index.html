ⓘ 原理与真机使用说明
外轮廓匹配：把固定轮廓（本例为铁盒外圈）的采样点投到取景画面，沿半径方向在 ±5% 容差内搜索梯度峰值。 「轮廓覆盖」= 命中边缘的点占比，「边缘锐度」= 命中强度，「特征色相似」= 轮廓内侧平均色与参考色的接近度； 三者加权后再过一条曲线得到对齐度。
像素徽章：按轮廓圆取景 → 缩小到 N×N → 有序抖动 → 映射到固定调色板 → 最近邻放大 ×18 → 叠上金属外圈、 齿纹、铆钉与环形刻字。
真机：手机浏览器调用摄像头需要 https:// 或 localhost。本地可直接 python -m http.server 后用桌面浏览器访问（localhost 也算安全上下文）。
换城市：把该城市的固定物做成透明底 PNG 上传即可，轮廓判定与徽章形状会跟着换。
